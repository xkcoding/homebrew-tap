# Homebrew Tap

Homebrew tap for [xkcoding](https://github.com/xkcoding) projects.

## Usage

```bash
brew tap xkcoding/tap
```

## Available Casks

| | Cask | Description | Install |
|---|------|-------------|---------|
| <img src="assets/ghostclip-logo.svg" width="28"> | [GhostClip](https://ghostclip.no-bug.dev) | Android <-> Mac clipboard sync | `brew install --cask xkcoding/tap/ghostclip` |
| | [DeepLens](https://deeplens.no-bug.dev) | Deep code analysis and documentation generator | `brew install --cask xkcoding/tap/deeplens` |

## Upgrade

```bash
brew upgrade --cask <cask-name>
```
